# 独自実装

* 自動DDS変換・キャッシュシステム
    * PNG・JPG・JPEG・TGA・HDR形式の元画像を、用途に合ったDDS形式へ自動変換します。
    * DDSの有無・更新日時・SHA-256ハッシュ・圧縮形式を比較し、必要な画像だけを変換します。
    * 最新のDDSがある場合は元画像よりDDSを優先して読み込み、テクスチャ読み込み時の負荷を軽減します。
    * DDSがない、または古い場合は元画像を読み込み、処理に時間がかかった画像をバックグラウンド変換キューへ登録します。
    * マニフェストとMutexを利用し、不要な再変換や変換処理の多重実行を防ぎます。
