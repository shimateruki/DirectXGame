# セーブ処理の改良

更新日: 2026-10-13

## 保存する情報と確定する時点

| 情報 | メモリへの反映 | ディスクへの反映 |
|---|---|---|
| 通常コイン・100枚到達時の残機 | 取得時 | 最初の取得から最大1秒以内。シーン移動・ゲーム終了時にも未保存分を保存 |
| プレイ時間 | 操作可能なシーンで経過した整数秒 | 30秒ごと。ほかの保存とシーン移動・終了時にも含める |
| スターコイン | ステージ中は `sessionStarCoins_` | ゴール時だけ。クリア記録と同じ1回の書込で確定 |
| ステージクリア | ゴール時 | スターコインと同じ1回の書込で確定 |

通常コインはゴールしなくても保存される。スターコインは死亡や退出だけでは永続化せず、ゴールした回の取得分を確定する。

## 安全な書込の流れ

`GameDataManager::Save()` は既存JSONを読み取り、管理外の項目を保ったまま管理項目を更新する。新しいJSONを同じフォルダの `.tmp` に書き、C++ストリームの `flush` と Windows の `FlushFileBuffers` を確認してから `MoveFileExW` で本体を置換する。直前の正常な本体は `.bak` に残す。本体が破損して読めない場合はバックアップを読み込む。両方読めない既存ファイルは上書きしない。

クリア時は `CommitStageClear()` がクリア情報とスターコインをまとめて保存する。失敗した場合は今回のクリアとスターコインのメモリ変更を戻し、成功表示とステージ選択への帰還を止める。チュートリアルの出口ゲートも閉じたままにする。プレイヤーにはエラーダイアログを一度表示し、5秒ごとに再試行する。通常コインや経過時間は別の保留情報として残る。

## プレイ時間の数え方

ゲーム本編・チュートリアル・ステージ選択の更新で時間を加算する。ロード、タイトル、ポーズ、操作案内、ゴール演出中は加算しない。タイトルのセーブ枠は既存の5枚の数字Spriteを `時:分` として使い、最大 `99:59` まで表示する。保存JSONには秒まで記録する。

## 確認状況

- Development x64 のビルドは成功。
- 実セーブを使わない隔離テストで、通常コインの時間差保存、プレイ時間、クリアとスターコインの一括保存、書込失敗時の旧データ保持と状態巻き戻し、破損本体からのバックアップ復旧を確認。
- ゲーム画面でのエラーダイアログ表示、ステージ移動後の再起動、長時間プレイ時の実画面表示は未確認。検証するときは実ユーザーのセーブを変更しない隔離環境を使う。
