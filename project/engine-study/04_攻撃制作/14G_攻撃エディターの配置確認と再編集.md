# 攻撃エディターの配置確認と再編集

## 現在の実装範囲（既存攻撃の移行状況）

「どの攻撃もシーンのようにObjectを選んで再編集できる」段階には、まだ達していません。
攻撃選択には次の区別を表示します。

| 表示 | 現在できること | まだできないこと |
|---|---|---|
| 数値調整のみ | 攻撃全体の威力・時間・距離などを調整 | 内部の槍・魔法陣などをObject一覧から選択して組み替える |
| 弾・放出の構成編集 | 弾ごとの本体・判定・軌跡・着弾を選び、時刻や移動も再編集 | 任意のScene Objectとして子部品を独立配置する |
| 部品編集 | 左の表示・判定・本体アニメーションの部品を選択して再編集 | 任意のScene Objectや全敵の既存攻撃を自動的に部品へ変換する |

具体例として、プリズムの「晶槍召喚陣」は数値調整の段階です。画面の槍や魔法陣の編集用一覧が出ないのは未移行のためです。
炎スライムの火球とプリズムの炎の扇状連射は、JSONの単発命令を使います。その後の改良で弾ごとの構成設定と保存前プレビューを追加しました。現在の操作と技術説明は [火球の構成編集と保存前プレビュー](14H_火球の構成編集と保存前プレビュー.md) を参照してください。
表示部品の一覧があるのは、部品トラックを持つ攻撃です。新規作成・見本からの作成で確認できます。

## 1. どこから使うか

編集モードでSceneを開き、Hierarchyの「敵攻撃プレビュー (Enemy Attack Preview)」を選びます。
炎スライムまたはプリズムの攻撃を選ぶと、左が「攻撃の構成」に切り替わります。
今回整理した操作は、この部品制作画面が対象です。

左側を上から順に使います。

1. 「対象の攻撃」で既存の攻撃を開く。
2. 表示部品を選ぶか、素材を選んで追加する。
3. 中央で見ながら右のInspectorで再編集する。
4. 左上の「保存」または「保存して攻撃を再生」を押す。

新規作成は「新しい攻撃を作る・見本から始める」を開きます。
従来のC++で動く攻撃には観測の案内が表示されます。その攻撃の内部処理が部品へ自動変換される機能ではありません。

## 2. Objectやエフェクトを中央へ出す

### 新しく追加する場合

1. 制作可能な攻撃を選ぶ。最初は見本の「照準・発射・追尾の例から作成」でも構いません。
2. 左の「＋ Object / エフェクト素材を選んで追加」を押す。
3. ポップアップの「素材を選択」を開き、画像と名前で選ぶ。
4. 選んだ素材が表示部品になり、中央の隔離ステージで配置確認が始まる。
5. 右の位置・回転・スケールを変更する。保存前でも配置確認に反映される。

対象素材は `Resources/json/effect` の **MeshEffect JSON** です。
ここでのObjectは攻撃の表示部品を意味します。任意のScene Object、Prefab、独立したGPU Particleの素材をすべてこのリストから追加できるわけではありません。
モデルを使った見た目も、MeshEffectとして保存されているものを選びます。

### すでに追加してある場合

左の `[表示]` が付いた部品を選ぶと、その部品の配置確認を開始します。
右の「この部品を画面に表示」からも開始できます。
「表示プリセット」で素材を差し替えられます。追加し直す必要はありません。

表示できない素材は左上の状態欄にパスと失敗を表示します。
JSONを修正した後は「配置確認をやり直す」を使います。読込失敗を毎フレーム繰り返さない実装です。

## 3. 配置確認と攻撃の再生は何が違うか

| 操作 | 読むデータ | 確認できる内容 | ファイルへの書込 |
|---|---|---|---|
| 部品選択・配置確認 | メモリ上の未保存の選択部品 | 素材、位置、回転、スケール、キー補間、指定時刻の見た目 | なし |
| 保存 | 編集中の攻撃プロファイルと共有アセット | 保存のみ。配置確認はそのまま | あり |
| 保存して攻撃を再生 | 保存後に再生成したActorの攻撃データ | 本体動作、追尾、接触、分岐を含む既存のランタイム経路 | あり |
| 保存済みへ戻す | ディスクのJSON | 保存時点の攻撃へ戻る | なし |

配置確認は**選択した表示部品ひとつ**の確認です。AIを停止し、表示条件や有効フラグに関係なく編集対象を表示します。
「見た目の確認位置」は部品開始からの秒数で、攻撃全体の実行時刻ではありません。
開始直後のフェードで見えにくい素材を避けるため、初期値は部品の長さの40%です。

キー移動はその時刻のキーを補間します。直進・追尾では生成位置を使い、飛翔の経路は再現しません。
追尾の向きや命中まで確認したい場合は「保存して攻撃を再生」を使います。
通常のタイムラインの再生操作も、配置確認を終了して保存済みの攻撃を再生します。

## 4. 再編集・複製・やり直し

### 同じ攻撃を直す

「対象の攻撃」から選び、部品や攻撃名を変更して保存します。
表示名を変えても内部のIDは変わりません。同じ攻撃が更新されます。
別の攻撃へ切り替えても、プロファイルを読み直すまでは編集内容はメモリに残ります。

### 元を残して別案を作る

「この攻撃を複製して編集」を使います。
新しいIDを割り当て、共有アセットへの参照を解除して中身を複製します。
複製を編集して保存しても、元の共有アセットを書き換えません。
保存すると新しい攻撃も本編の候補になります。射程、優先度や抽選重みを確認してください。

### 保存済みへ戻す

「保存済みへ戻す」は、その敵のプロファイル全体を読み直します。
未保存の変更がある場合は、破棄するか編集を続けるかを選ぶ画面が出ます。
読込が成功するまでは編集中のプロファイルを置き換えません。失敗時は編集内容が残ります。
同じ攻撃IDが残っていれば、開き直した後もその攻撃を選択します。

「元に戻す」「やり直す」は部品構成の編集履歴です。
攻撃自体の追加・削除、攻撃名など全操作を戻す履歴ではありません。攻撃を切り替えると部品履歴も切り替わるため、保存済みへの復帰とは区別してください。

## 5. 保存先と共有

通常の攻撃は敵ごとの `Resources/json/enemy_attack/*.json` に保存されます。
「詳細: 共有攻撃アセット」で参照を付けた場合、攻撃内容は共有JSONから読み込まれます。
共有素材の内容を変えると他の利用先にも影響します。個別に調整したい場合は「共有を解除して埋め込みにする」か、攻撃の複製を使います。
現状、保存ボタンで更新する共有アセットは選択中の攻撃の参照先です。共有部品を編集した場合は、その攻撃を選択したまま保存してから別の攻撃へ切り替えてください。複数の共有アセットを編集して最後に一括保存する管理には、まだ対応していません。左側にもこの制約を表示します。
素材の見た目そのものはMeshEffect Editorで編集します。この画面では素材参照、配置、動作と判定を組み合わせます。

## 6. 実装の仕組み

### 配置確認の生成と時間

`EnemyAttackPreviewWindow::BeginPlacementPreview()` は既存の隔離ステージを準備し、Actorの固定ステップ再生を停止します。
`MeshEffectManager::CreateEffectScope()` で、この確認表示だけを止められる所有IDを確保します。
`StartTimelineEffect()` がJSONから表示物を生成し、通常の経過時間による自動更新の対象から外します。

毎フレームの `UpdatePlacementPreview()` は未保存の部品を読み、
`AttackSequenceTrack::Evaluate()` に指定秒を渡してキーを補間します。
位置は術者原点と標的方向から作る「右・上・前」の基底でワールド座標へ変換します。
回転の単位はラジアンです。スケールは表示部品の倍率です。

最後に `EvaluateTimelineEffect()` に位置・回転・スケールと絶対時刻を渡します。
差分時間を積み重ねないので、位置を調整してもタイムラインを先頭から再生する必要がありません。
これは**絶対時刻サンプリング**と**編集用のデータ駆動表示**の組み合わせです。

### 解放

部品を切り替える、停止する、Sceneが切り替わる、通常再生へ戻る際に表示スコープを解放します。
素材パスが変わった場合だけ素材を生成し直し、位置・スケールの変更では生成し直しません。
配置確認専用の経路から攻撃判定やダメージイベントは実行しません。

### 安全な再読込

`ReloadAuthoringProfile()` は一時的な `EnemyAttackProfile` にファイルを読み込み、成功後に編集対象を置換します。
これは**トランザクション的な置換**です。読込途中の壊れた状態を編集対象へ露出させません。
選択の復元には配列番号ではなく攻撃IDを使います。
