## 実装との照合で訂正した説明

### GPU シークは毎ステップの GPU 再シミュレーションではない

CPU の Update を 1/60 秒ずつ呼んでも、その呼出しごとに Dispatch は起きない。GPU 処理は Draw 側で行われる。リセット後は発生時の年齢から運動を近似復元するため、Field・乱流・過去の深度衝突を同じ履歴として再現する保証はない。対応するコードコメントと概要章も修正した。

### 固定更新の入口と使用実績は別

固定更新を蓄積して呼ぶ仕組みはあるが、Object3d の基底実装は空。現行 `engine` / `game` の調査では派生実装が見つからない。通常 Update で進む処理を「すべて固定刻み」とは説明しない。

### API 名から強い保証を推測しない

Cast は離散 Overlap、NavAgent の失敗時は直接方向である。保存対象のラベルが返ることと全ファイルの書込成功も区別する。詳しくはそれぞれの詳細章を参照する。
