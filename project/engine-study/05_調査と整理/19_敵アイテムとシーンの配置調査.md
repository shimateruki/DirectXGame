# 敵・アイテム・シーンの配置調査

調査日: 2026-10-09

追記: この表は整理前の調査記録です。`BossCore`、`Mushroom`、`Bat`、`BeamDrone`は後続の未使用要素整理でFactory、Editor、サンプル配置から削除しました。

## 調査方法

- 敵は `game/actor/enemy/spawn/EnemyFactory.cpp` に登録された15種類を対象にした。
- ステージ1・2・3の `_enemy.json`、`_object.json`、`_player.json` にある各 `objects[].enemyType` と、`Spawner` の `param.enemyType` を確認した。`_object.json` に直接記録された敵も `LevelLoader.cpp` が敵として生成する。
- アイテムは `game/system/ItemFactory.cpp` と `Resources/json/3Dobject` の全シーン配置ファイルを確認した。
- 以下は配置状況の記録であり、削除可否の判定ではない。

## ステージ1・2・3に直接配置されていない敵

15種類のうち9種類は3ステージのいずれかに配置されている。残る6種類は次のとおり。

| 敵種別 | 確認できた別の経路 |
|---|---|
| `BossCore` | Factory登録とステータス設定あり。ステージ1・2・3の配置なし |
| `Bomb` | `sample_enemy.json`に配置あり。`EnemyBomber.cpp` と `BomberCopyAbility.cpp` からも生成 |
| `Mushroom` | `sample_enemy.json`に配置あり |
| `WindSlime` | `level_design_sample_enemy.json`に配置あり。プレイヤーのコピー能力にも関連 |
| `Bat` | プレイヤーの変身・運搬処理に種別参照あり |
| `BeamDrone` | プレイヤーの変身・コピー種別に参照あり |

特に`Bomb`は直接配置がなくてもゲーム中に生成されるため、配置数だけで未使用とは判定できない。`BossCore`を含むほかの種類も、サンプル・エディター・プレイヤー側の依存を確認してから扱う。

## アイテム

Factoryに登録されているアイテム種別は`Heal`のみ。`Resources/json/3Dobject`内のシーン配置JSONには、`itemType`が設定されたObjectも`type`が`Item`のObjectも見つからなかった。`Heal`のプリセット、エディターの作成メニュー、`LevelLoader.cpp`の生成処理は存在する。現行シーンへの配置がないという意味で、今後使う予定があるかを確認する候補。

## シーンデータ

|---|---|
| `abc` | `_player`、`_enemy`、`_object`、`_camera`の配置数がすべて0。Scene Assetの表示名は`New Scene` |

`SceneSerializer.cpp`が固定の実行時参照シーンとして挙げている`sample`は、`PreviewScene.cpp`の既定パスにも使われるため、この表の空シーンと同列には扱わない。`abc`と`new_scene`もエディターから開ける可能性があるため、所有者の判断まで削除しない。
