# 全クラスのコメント・可読性再点検

[目次](../00_目次と読み方.md)

## 対象と点検方法

自作 C++ の engine、game、tools/TextPngTool を対象に、クラス・内部クラス・構造体を一覧化した。外部ライブラリ、ビルド生成物、提出物の生成コピーは対象外。resource.h は型定義を持たないリソース識別子ヘッダー。

型の役割説明を全件確認し、説明漏れの候補はメンバーと周辺の利用処理を読んで補足した。全ソースには関数間の区切り・過剰な空行の走査も行った。コメントがない全関数へ定型文を足す方法は取らず、所有権・時間単位・失敗時・近似の制約が必要な API を追加で修正した。

この一覧は型定義の網羅性を確認するための記録であり、全関数の全分岐について正しさを証明するものではない。

## 今回修正した説明の例

- 描画リソース：SRV 番号と画像所有権、定数バッファの 256 バイト間隔。
- 保存と編集：Prefab の値差分と構造差分、Play 前後の比較、Undo の保留キャンセル。
- Replay：姿勢フレーム・入力サンプル・診断統計・保存待機データの役割。
- ゲーム：能力セッション、ボスの攻撃表示の寿命、演出後の復元情報。
- 実行時契約：離散 Cast、経路探索の直接方向へのフォールバック、入力デバイスごとのエッジ。
