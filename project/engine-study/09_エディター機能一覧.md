# エディター全機能の地図


[目次](00_目次と読み方.md)へ。画面名から「何を編集するか」「何の技術でできているか」「どこまで保存・検証できるか」を引くための索引。個別の詳しい処理は各章とリンク先の実装を読む。登録・表示の起点は [`DebugEditor`](../engine/utility/SystemDebug/editor/core/DebugEditor.cpp)、[`EditorManager`](../engine/utility/SystemDebug/editor/core/EditorManager.cpp)、[`GameEditorController`](../engine/core/editor/GameEditorController.cpp)。

## シーンを組み立てる画面

| 画面・機能 | 技術名と仕事 | 確認する境界・コード |
| --- | --- | --- |
| [Hierarchy](../engine/utility/SystemDebug/editor/windows/HierarchyWindow.cpp) | Object ツリーを列挙して選択する。 | 選択は保存ではない。Inspector の編集対象になる。 |
| [Inspector](../engine/utility/SystemDebug/editor/windows/inspector/InspectorWindow.cpp) | 型別 UI で Object / Component の値を変更。敵・ギミック・アイテム・材質等は分割実装。 | 変更後は Scene Serializer の対応キーを確認。 |
| [Project](../engine/utility/SystemDebug/editor/windows/ProjectWindow.cpp) | Asset Database の内容からアセットを選ぶ。 | ファイルの存在と現在シーンへの適用は別。 |
| [Scene Workspace](../engine/utility/SystemDebug/editor/core/SceneWorkspace.cpp) | Scene Asset 操作と編集視点ブックマーク。 | Play 中の視点を編集用ブックマークへ混ぜない。 |
| [Scene Save Preview](../engine/utility/SystemDebug/editor/windows/SceneSavePreview.cpp) | 保存予定 JSON と現行 JSON の差分比較。 | 差分表示後に保存操作が必要。 |
| [Scene Inventory](../engine/utility/SystemDebug/editor/windows/SceneInventoryWindow.cpp) | Object をカテゴリ・表示状態などで集計、一覧化。 | 現在読み込まれたシーンの棚卸し。 |
| [Preset Editor](../engine/utility/SystemDebug/editor/core/PresetEditor.cpp) | 再利用できる設定を編集。 | Preset・Object・Scene の保存先を混同しない。 |
| [Quick Search](../engine/utility/SystemDebug/editor/core/EditorQuickSearch.cpp) | コマンドや対象の検索窓。 | 検索結果は操作への入口。 |
| [Built-in Create Presets](../engine/utility/SystemDebug/editor/core/BuiltInCreatePresetRegistry.cpp) | Object 生成時の既定パラメータ候補。 | 生成後の Object は独立した状態を持つ。 |

## 裏側の共通機構

[`EditorCommandRegistry`](../engine/utility/SystemDebug/editor/core/EditorCommandRegistry.cpp) はコマンド登録、[`EditorToolSettings`](../engine/utility/SystemDebug/editor/core/EditorToolSettings.cpp) はツール設定、[`EditorTransactionManager`](../engine/utility/SystemDebug/editor/core/EditorTransactionManager.cpp) は Undo / Redo、[`AssetDatabase`](../engine/utility/SystemDebug/editor/core/AssetDatabase.cpp) はアセット索引、[`SceneSerializer`](../engine/utility/SystemDebug/editor/core/SceneSerializer.cpp) は Scene JSON 化を担当する。専用ウィンドウはこれらを呼ぶ利用者側。UI ファイルだけ読んでも「保存したか」「本番で動くか」が分からない理由は、この役割分担にある。
