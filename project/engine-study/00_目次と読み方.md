# CG2 エンジン・エディター実装読本

このフォルダーは、現行コードの仕組みを学ぶ章と、ある時点の調査・修正記録を分けて読むための個人用ノートです。対象は `project/engine`、`project/game`、関連する `Resources` です。章番号は執筆時の識別子であり、現在の完成度や実行順を表しません。

## フォルダーの分け方

| フォルダー | 内容 |
| --- | --- |
| `01_基礎と実行基盤` | ゲームループ、DirectX 12、入力・衝突、数学、ロード |
| `02_描画と演出` | シェーダー、粒子、VFX、アニメーション |
| `03_エディターと保存` | Scene編集、Undo、制作ツール、Replay Debugger |
| `04_攻撃制作` | 攻撃・能力プレビューと制作工程（14〜14K） |
| `05_調査と整理` | 設計調査、配置・未参照候補、プレイヤー体験 |
| `06_修正記録` | 実装した変更と引継ぎ事項 |

このファイルと二つの「資料案内」は直下に置き、各資料への入口にしています。同じ番号の資料があっても、フォルダーと題名で区別できます。

## 迷ったときの読み順

1. [01 ゲームループ](01_基礎と実行基盤/01_ゲームループとエディター基盤.md)で Update、Draw、SceneManager の位置をつかむ。
2. [分野別目次](資料案内_技術解説.md)から対象機能の概要章を読む。
3. 同じ分野の `A`、`B` などの詳細章でデータ、計算、処理順、制限を追う。
4. 最近の変更の理由や検証結果が必要な場合は[調査と変更履歴](資料案内_調査と変更履歴.md)を読む。

## 説明を読む際の境界

**編集値と保存値は別です。** Inspector で値を変えた後、どの JSON にいつ保存されるかは機能ごとに異なります。[シーン編集](03_エディターと保存/06_シーン編集とデータ保存.md)と[Undo・保存](03_エディターと保存/06A_Undoと保存のデータ設計.md)を参照してください。

**プレビューと Play は別です。** 専用ステージでは独自の対象・時計・再構築処理を使うため、敵 AI、衝突、地形との相互作用の全再現を意味しません。[攻撃プレビュー](04_攻撃制作/14_攻撃能力プレビュー.md)を参照してください。

**Undo、Backup、Replay は別です。** それぞれ編集操作の履歴、保存ファイルの退避、ゲーム状態の記録と再生です。[06A](03_エディターと保存/06A_Undoと保存のデータ設計.md)と[13](03_エディターと保存/13_リプレイデバッガー.md)を参照してください。

**調査記録は調査時点の内容です。** 後の実装修正で変わることがあります。現在の挙動を判断するときは、リンク先のコードと最新の変更記録を確認してください。各資料の保存場所は二つの資料案内からたどれます。
