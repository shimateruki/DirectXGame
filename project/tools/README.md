# Tools

エンジン外で動かす制作補助ツールを用途別に整理しています。

| フォルダ | 用途 |
| --- | --- |
| `asset_audit/` | 重いアセットや未使用候補を調査する監査ツール |
| `dds_cache/` | PNG などを DDS に変換してキャッシュするツール |
| `docs/` | 仕様書などのドキュメント生成ツール |
| `json_backup/` | JSON の変更を監視してバックアップするツール |
| `model_generation/` | 制作用の簡易モデル生成ツール |
| `model_lod/` | LOD モデル生成ツール |
| `shader_texture/` | シェーダー用テクスチャ生成・ベイクツール |
| `sprite_generation/` | UI や演出用 Sprite 生成ツール |
| `terrain/` | 地形メッシュ生成ツール |

エンジン側から呼ぶツールは、各 Editor のコードでこのフォルダ構成に合わせて参照しています。
